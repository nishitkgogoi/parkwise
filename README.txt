Where Did I Park? (P07 Concept D) — Zero-npm PWA Bundle
=========================================================

How to run locally:
  - Open index.html directly in any browser (no npm or server required).

How to install as an Android PWA or export an APK:
  1. Drag and drop this extracted folder onto Netlify Drop (https://app.netlify.com/drop)
     or push to GitHub Pages (HTTPS is required by browsers for PWA install).
  2. Open the HTTPS URL in Chrome on Android and tap "Add to Home screen" / "Install app".
  3. Optional APK: Paste your hosted HTTPS URL into https://www.pwabuilder.com/ to
     generate a downloadable Android APK package.

QR Deep-Link Support:
  Append ?lot=B34&section=A1 (or B56, BH1, BH4 with A1, A2, B1, B2) to pre-fill
  the rider's parking section automatically.
